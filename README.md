# 📚 Study Circle

**Study Circle** is a student-focused collaborative learning platform designed to make learning more organized, accessible, and engaging. It provides students with a simple digital environment to access study resources, connect with peers, and manage their learning activities.

## ✨ Features

* 📖 Access and share study resources
* 👥 Peer collaboration and interaction
* 📝 Organized learning activities
* 🎨 Clean and user-friendly UI/UX
* 📱 Responsive design for different screen sizes
* ⚡ Simple and intuitive navigation

## 🛠️ Technologies Used

* **HTML5** – Structure and content
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactive functionality
* **Figma** – UI/UX design and prototyping

## 🎯 Project Objective

The main objective of Study Circle is to create a **simple, user-friendly, and collaborative digital learning environment** where students can organize their study activities and share useful learning resources.

## 🚀 Future Enhancements

* User authentication and profiles
* Real-time peer collaboration
* Discussion forums
* Resource categorization and search
* Progress tracking
* Backend and database integration
